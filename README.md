# Bible Study Guides

Offline-friendly Bible topic study guides (ten topics) with quizzes, KJV & NIV memory verses, Matthew Henry and Jamieson-Fausset-Brown commentary notes, and tappable verse links to YouVersion / Bible Gateway.

## Use it

Open the live site (GitHub Pages). On a phone, use **Add to Home Screen** / **Install** to install it as a Progressive Web App. Content caches for offline use; Bible and commentary links still need network and open in their apps or the browser.

## Android APK

A signed Android WebView package is built separately as `BibleStudyGuides.apk`.
